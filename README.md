# Menulux - Restaurant Management System

A responsive front-end system for managing restaurant operations, including orders, tables, menus, and staff workflows. Built during my internship at NDM Software.

🔗 **Live Demo:** [https://awabismailelazhariomerabdelgadir.github.io/MenuluxEn/](https://awabismailelazhariomerabdelgadir.github.io/MenuluxEn/)

## About The Project
Menulux is a web-based restaurant management interface that helps staff handle daily operations efficiently.  
It includes modules for order management, table status, menu editing, kitchen view, and basic administration.  
The goal was to translate business requirements into a clean, functional, and responsive user interface.

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
- Git & GitHub

## Features
- Responsive design for desktop and mobile
- Order management interface
- Table and menu management
- Kitchen and cashier views
- Clean and user-friendly UI components
